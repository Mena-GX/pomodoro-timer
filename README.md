# 🍅 Pomodoro Timer

A desktop Pomodoro Timer built with **ElectronJS**, **HTML**, **CSS**, and **JavaScript**. This project combines a simple productivity tool with a custom-designed interface and artwork created specifically for the application.

The goal of this project was to practice building a desktop application with Electron while exploring timer functionality, UI design, application structure, and creating a polished user experience.

## ✨ Features

* ⏱️ **Pomodoro Timer** — Use timed focus sessions to structure work and study periods.
* ☕ **Break Sessions** — Take dedicated breaks between focus sessions.
* ▶️ **Start / Pause / Reset** — Easily control the current timer session.
* 🎨 **Custom UI Design** — The interface and visual elements were designed with a focus on creating a fun and approachable experience.
* 🖌️ **Original Artwork** — All artwork used throughout the application was created by me specifically for this project.
* 🖥️ **Desktop Application** — Built with ElectronJS to run as a standalone desktop application.
* 🔄 **Session-Based Workflow** — Switch between focused work periods and breaks to follow the Pomodoro technique.

## 🍅 What is the Pomodoro Technique?

The Pomodoro Technique is a time-management method that breaks work into focused intervals separated by short breaks.

A typical cycle consists of:

1. **25 minutes** of focused work
2. **5 minutes** of rest
3. Repeat the cycle
4. Take a longer break after several completed sessions

The timer provides a simple way to follow this workflow without needing to keep track of the intervals manually.

## 🚀 Getting Started

### Prerequisites

Before running the project, make sure you have:

* [Node.js](https://nodejs.org/) installed
* npm installed
* Git installed

### Installation

Clone the repository:

```bash
git clone https://github.com/Mena-GX/pomodoro-timer.git
```

Navigate into the project directory:

```bash
cd pomodoro-timer
```

Install the project dependencies:

```bash
npm install
```

### Running the Application

Start the Electron application with:

```bash
npm start
```

The application should open in its own desktop window.
